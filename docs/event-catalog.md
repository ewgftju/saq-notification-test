## Подстановка параметров

Параметры подставляются из зафиксированного события и доверенных справочников. Если срока или необязательного поля нет, соответствующая фраза целиком убирается. Нельзя отправлять сообщения с незаполненными фигурными скобками. Названия документов следует хранить в шаблонах в корректной форме либо отделять двоеточием, не склеивать произвольные падежи. RU/KZ требуют отдельных редакций. Для реального получателя применяется краткий текст с разрешёнными данными.
