# Проверка макета

Дата: 05.10.2026.

## Результат

- `npm test`: 14 проверок логики пройдены.
- `npm run build`: статическая сборка успешна.
- Синтаксис исходных JS и автономного HTML проверен.
- В Chromium выполнено 10 групп сквозных проверок; ошибок JavaScript страницы не обнаружено.
- Просмотрены настольная лента, открытый колокольчик и мобильные экраны. Проверка мобильного размера: 390 × 844; настольного: 1440 × 1000.

## Сквозные сценарии

1. Уведомление и поручение открывают один и тот же документ.
2. Согласование активирует следующий этап утверждения; итог приходит инициатору.
3. СУР: исключение без причины блокируется; после завершения результат сохраняется и поступает исходному отправителю.
4. Прочтение документа не подтверждает ознакомление; отдельное подтверждение уведомляет отправителя.
5. Ответ члена комиссии о присутствии приходит организатору.
6. «Все прочитаны» сохраняет открытые поручения; поиск, архив и сохранение после перезагрузки работают.
7. Каталог содержит 58 событий, фильтры по модулю и раскрываемые шаблоны.
8. Неназначенный тестовый пользователь не может открыть карточку чужого документа через прямую ссылку.
9. Мобильные лента и колокольчик помещаются по ширине экрана.
10. Ошибок выполнения JS во время этих сценариев нет.

Это проверки frontend-демонстрации, а не доказательство серверной авторизации или юридической значимости операций. Полные версии документов, настоящая ЭЦП, доставка между реальными пользователями и пятью модулями не подключены.
